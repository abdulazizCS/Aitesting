# جازي — المرشدة الافتراضية لجامعة جازان

مرشدة افتراضية ثلاثية الأبعاد (Three.js) على شكل روبوت لطيف (رأس أخضر بشاشة وعينين مضيئتين وابتسامة برتقالية وهوائي أصفر) بصوت امرأة سعودي، لشاشات العرض الطولية في ملتقى التحول الرقمي 2026 «قيمة وأثر». يجيب الزوار بالصوت والحركة والبطاقات المرئية، ويقدّم تحدي معرفة تفاعلياً.

## التشغيل على شاشة المعرض
افتح الرابط بهذه الصيغة على متصفح Chrome أو Edge:
```
https://abdulazizcs.github.io/Aitesting/?kiosk=1
```
- `kiosk=1`: وضع المعرض (ملء الشاشة، منع القوائم والاختصارات والرجوع، وعدم ظهور لوحة مفاتيح الجهاز).
- `rotate=90`: تدوير الصفحة إذا كانت الشاشة مركبة على جنبها (0 / 90 / 180 / 270).
- `localvoice`: تشغيل جازي دون ElevenLabs (إجابات محلية وصوت المتصفح).
- `lite`: نسخة أخف للأجهزة الضعيفة.

لتشغيل المتصفح كتطبيق معرض كامل على ويندوز:
```
chrome.exe --kiosk --autoplay-policy=no-user-gesture-required --use-fake-ui-for-media-stream "https://abdulazizcs.github.io/Aitesting/?kiosk=1"
```
ضع الاختصار في مجلد بدء التشغيل (`shell:startup`) ليعود العرض تلقائياً بعد انقطاع الكهرباء أو إعادة تشغيل الجهاز.

**أدوات الشريط العلوي:** التحكم في مستوى الصوت (كتم، خفض، رفع، وشريط تمرير)، وزر ملء الشاشة، وزر التدوير.

**تدوير الصفحة:** زر ⟳ في الشريط العلوي يدوّر الصفحة 90° في كل ضغطة (0° → 90° → 180° → 270°)، ويُحفظ الاختيار على الجهاز. ويمكن أيضاً تحديده من الإعدادات أو من الرابط (`rotate=90`).

**الإعدادات:** اضغط مطولاً على شعار الجامعة ثانيتين (أو F2): التدوير، مستوى الصوت، وضع المعرض، مدة العودة للبداية، اختبار الاتصال بالصوت والمحادثة، وإحصاءات الاستخدام.

## تجربة الزائر
1. **شاشة ترحيب** تظهر تلقائياً عند عدم وجود زائر، وجازي يلوّح ويدعو للتفاعل.
2. **المس الشاشة للبدء**: يلتفت جازي ويبتسم ويرحّب بصوت سعودي.
3. **تحدث مباشرة دون ضغط أي زر**: بعد بدء الزيارة يبقى الميكروفون مفتوحاً ويكتشف جازي بداية الكلام ونهايته. يمكن إيقاف الميكروفون وتشغيله بلمس شريط الميكروفون أسفل الشاشة.
4. **حالات واضحة**: يستمع / يفكر / يتحدث، مع ترجمة نصية متزامنة للكلام.
5. **بطاقات معلومات** تظهر حسب السؤال (أرقام متحركة، خطوات، خدمات قابلة للمس، رموز QR)، وجازي يشير إليها وينظر نحوها.
6. **الخيارات في أعلى الشاشة**: أزرار المواضيع للتنقل بينها، و«أعد الإجابة»، و«اكتب سؤالك» بلوحة مفاتيح عربية/إنجليزية على الشاشة.
7. **تحدي المعرفة**: 5 أسئلة، مؤقت 20 ثانية، 10 نقاط لكل إجابة صحيحة، احتفال بالنتيجة.
8. **العودة للبداية** بعد فترة عدم نشاط (60 ثانية افتراضياً) مع إنهاء جلسة الزائر السابق.

## الملفات
| الملف | الوصف |
|---|---|
| `index.html`, `style.css` | الواجهة بهوية الملتقى (تتكيف مع الشاشة الطولية والعرضية) |
| `app.js` | الشاشات، الجلسات، البطاقات، لوحة المفاتيح، التحدي، الإعدادات، وضع المعرض |
| `robot.js` | شخصية جازي ثلاثية الأبعاد: الطفو، الإمالة والقفز، الهوائي المرن، التعابير، حركة الفم، إضاءة الأذنين أثناء الكلام |
| `robot-mohammed.js` | الشخصية السابقة (جازي)، محفوظة للرجوع إليها |
| `voice.js` | الصوت: وكيل ElevenLabs بأسلوب «اضغط وتحدث» + صوت المتصفح احتياطياً |
| `brain.js` | الإجابات المحلية (احتياطي دون إنترنت) واختيار البطاقة المناسبة |
| `content.js` | **محتوى البطاقات وأزرار المواضيع** — عدّله لتغيير ما يظهر على الشاشة |
| `quiz.js` | أسئلة تحدي المعرفة (من ملف هوية الملتقى) |
| `kb.js` | قاعدة المعرفة المولّدة من `data/jazanu-site.md` |
| `sw.js`, `vendor/` | التشغيل دون إنترنت (نسخ محلية من المكتبات) |

## تحديث المعلومات
- معلومات الجامعة: عدّل `data/jazanu-site.md` ثم شغّل `python3 tools/build_kb.py`، وارفع الملف نفسه لقاعدة معرفة وكيل ElevenLabs.
- البطاقات والمواضيع: `content.js`. أسئلة التحدي: `quiz.js`.

## الصوت والخصوصية
- الصوت البشري من وكيل ElevenLabs. الصفحة تحتوي معرّف الوكيل العام فقط، **ولا تحتوي أي مفتاح سري**. قيّد الوكيل بنطاق الموقع من لوحة ElevenLabs (Security → Allowlist).
- لا تُحفظ تسجيلات أو بيانات للزوار في الصفحة. الإحصاءات أرقام مجمّعة محفوظة على جهاز العرض فقط.

```
python -m http.server 8000
```

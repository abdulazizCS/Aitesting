# محمد — المساعد الذكي لجامعة جازان

روبوت تفاعلي ثلاثي الأبعاد (Three.js) بالزي السعودي، يجيب بالصوت والحركة عن أسئلة الزوار حول جامعة جازان، بتصميم مطابق لهوية ملتقى التحول الرقمي.

## المزايا
- **إجابات من بيانات الجامعة:** ردود مُعدّة للأسئلة الشائعة (الرئيس، النشأة، الأرقام، الكليات، القبول، التواصل، التصنيفات...) وبحث نصي في قاعدة المعرفة لبقية الأسئلة، مع رابط المصدر.
- **كلام واقعي:** نطق عربي (Web Speech API) وحركة فم مبنية على حروف الجملة (فتح، تدوير، إغلاق للشفاه) ومتزامنة مع الكلمات.
- **حركة طبيعية:** إيماءات يد بالـ IK، تنفس، نقل وزن، رمش، نظرات سريعة للعين، وتمايل البشت مع الحركة.
- **صوت بشري عبر ElevenLabs:** محادثة صوتية حية مع وكيل ElevenLabs (صوت سعودي، وقاعدة معرفة من بيانات الجامعة)، وحركة الفم تتبع مستوى الصوت الحقيقي. معرّف الوكيل في `ELEVEN_AGENT_ID` داخل `robot.js`.
- **احتياطي تلقائي:** إذا تعذّر الاتصال بـ ElevenLabs (أو رُفض الميكروفون) يكمل محمد بالإجابات المحلية وصوت المتصفح. أضف `?localvoice` للرابط لفرض هذا الوضع.

## الملفات
| الملف | الوصف |
|---|---|
| `index.html`, `style.css` | الواجهة بهوية الملتقى |
| `robot.js` | المشهد ثلاثي الأبعاد والحركة والكلام |
| `brain.js` | محرك الإجابات |
| `kb.js` | قاعدة المعرفة (مولّدة) |
| `data/jazanu-site.md` | بيانات موقع الجامعة (المصدر) |
| `tools/build_kb.py` | يولّد `kb.js` من ملف البيانات |

## تحديث المعلومات
عدّل `data/jazanu-site.md` ثم شغّل:
```
python3 tools/build_kb.py
```
وللإجابات المُعدّة عدّل قائمة `INTENTS` في `brain.js`.

## التشغيل محلياً
```
python -m http.server 8000
```
ثم افتح `http://localhost:8000`.

## تدوير الصفحة (لشاشات العرض)
زر **تدوير** في الشريط العلوي يدوّر الصفحة 90° في كل ضغطة (0، 90، 180، 270)، ويُحفظ الاختيار على نفس الجهاز. ويمكن تحديده من الرابط مباشرة، مثل `?rotate=90`. عند الوضع العمودي تنتقل لوحة المحادثة إلى أسفل الشاشة تلقائياً. أضف `?lite` للرابط لتشغيل نسخة أخف على الأجهزة الضعيفة.

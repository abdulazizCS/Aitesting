# رافد — روبوت تفاعلي ثلاثي الأبعاد

موقع من صفحة واحدة يعرض روبوتاً ثلاثي الأبعاد (Three.js) بالزي السعودي، يتكلم بالعربي ويتحرك.

- حركات يد بالـ IK: تلويح، يد على الصدر، تقديم، تفكير، إيماءة، رقص
- وجه متحرك: رمش، نظر يتبع المؤشر، حركة فم مع الكلام
- نطق عربي (Web Speech API) وإدخال صوتي بالميكروفون
- محادثة بردود عربية جاهزة

## التشغيل

```
python -m http.server 8000
```
ثم افتح `http://localhost:8000` في Chrome أو Edge (الميكروفون يتطلب localhost أو https).
